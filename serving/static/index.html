Research demo · not a medical device

Diabetic retinopathy referral from a single fundus photograph.

A five-fold EfficientNet-B0 ensemble trained on APTOS-2019 and tested, untouched, on a second clinic in India and a French screening set graded by a specialist panel. It returns a severity grade and a referral decision, and it shows you where it is known to be wrong.

02 · Evidence
Held-out test vs. two other populations

      
IDRiD: another clinic and camera, one fixed resolution. Messidor-2: France, graded by a panel of three retina specialists. The model saw each once, with no fine-tuning and no refitted thresholds.

    

    

      

        
APTOS test (in-distribution)IDRiDMessidor-2

        

      

      

        
Shortcut
QWK 0.652

          
reached by a classifier that sees only file metadata (resolution, brightness, file size) and never the retina. Camera correlates with disease in APTOS.

        
Pre-registered test
Specificity ↑

          
A shortcut-dependent model should have over-called disease on IDRiD, where the shortcut is unavailable. The prediction was written down first. It failed: specificity rose.

        
Label ceiling
≈ 84%

          
Duplicate images carry conflicting grades 29% of the time. No model can be more right than its labels.

        
Second external set
AUC 0.819

          
On Messidor-2 the prediction written first (AUC ≥ 0.93) failed. Moderate eyes without exudates are scored like Mild: the model learned where APTOS's single graders draw that line.

      

    

  


  
  

    

      
03 · Pipeline
From upload to decision

      
The same preprocessing code that built the training cache runs on your upload, so the served model cannot drift from the evaluated one.

    

    

      
Quality gate
Rejects images too dark, too bright or unreadable before any scoring.

      
Auto-crop
Finds the circular fundus and trims the black border around it.

      
Square & resize
Pads to square at 512, then resizes to 384 and normalises.

      
5-fold ensemble
Five EfficientNet-B0 regressors in ONNX Runtime, one CPU thread each.

      
Thresholds
The mean score is cut at four thresholds fitted on validation data.

      
Decision
Grade 0–4, plus referable when grade ≥ 2.

05 · API
Use it from code

      
Plain HTTP. Model card at /model-card, interactive docs at /docs.

    

    

      

        
POST
/predict
multipart file. Returns grade, referable, raw score, fold scores and spread. ?preview=true adds the preprocessed image.

        
GET
/model-card
Reported metrics and known limitations as JSON.

        
GET
/health
Liveness, and whether the ensemble is loaded yet.
